An entry for make.fun's **One-Liner Laugh Lab** — one short funny line
answering the prompt: the excuse a robot vacuum gives after eating a sock.

The line: *"I didn't eat your sock — I took it hostage. It's under the
couch now, demanding ransom in fabric softener."*

The joke turns a household accident into a hostage negotiation: the vacuum
isn't sorry, it's bargaining, and the ransom it names is the one thing a
sock actually wants. Short, specific, and no stock robot joke.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set), then reads it back and refuses to finish unless the text
is 1–200 characters and not only whitespace.
